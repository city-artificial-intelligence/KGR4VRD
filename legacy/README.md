# Historical reference snapshot

These directories preserve the original tracked scripts and experiment-space CSVs
from revision `08bb8e5f79e5c0737b2c45334ef5745e17c06006`, byte for byte. They contain
the known scientific and operational defects described in the specifications and
are not supported entry points. Do not use their pipeline scripts for corrected
experiments. The active package never imports this tree.

Use `kgr4vrd` and [the running guide](../docs/running-experiments.md). Older code
paths named in the unchanged specifications now live below `legacy/`. The submitted
manuscript and review files remain in their original `paper/` directory.
